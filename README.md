## Описание проекта
Это консольное приложение на C++, которое автоматически подбирает индивидуальный тренировочный план на основе данных пользователя. В приложение встроена система уровней-рекордов в базовых движениях поверлифтинга со званиями для повышения интереса к тренировкам

Программа анализирует введённые параметры (уровень подготовки, цель, доступное время, ограничения по здоровью, питание) и на основе алгоритмов и заданных упражнений формирует оптимальный тренировочный план.
