## Описание проекта
это консольное приложение на C++, которое автоматически подбирает индивидуальный тренировочный план на основе данных пользователя и его целей.

Программа анализирует введённые параметры (уровень подготовки, цель, доступное время, оборудование, ограничения по здоровью) и на основе заложенных алгоритмов и базы упражнений формирует оптимальный план тренировок на заданный период.
